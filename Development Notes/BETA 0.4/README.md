# Forja — BETA 0.4: teclas em linha

- As quatro notas da pauta agora usam as teclas **1 2 3 4**, em linha como um teclado, do grave para o agudo:
  - **1** = TOM (grave)
  - **2** = TAM
  - **3** = TAN
  - **4** = TIN (agudo)
- O teclado numérico também funciona.
- **ESPAÇO** vira a peça. O clique direito continua valendo.
- As letras W/A/S/D e as setas não tocam mais as notas.
- Os rótulos da pauta e a dica do topo mostram as teclas novas.
