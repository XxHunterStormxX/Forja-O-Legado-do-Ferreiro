# Forja: O Legado do Ferreiro

Jogo de simulação de ferraria em pixel art, feito em um único arquivo HTML: a arte é desenhada por código e a música é gerada pelo navegador (Web Audio). Não há arquivos de imagem nem de áudio.

## Como jogar

Abra `Development Notes/Forja_O_Legado_do_Ferreiro.html` em um navegador. Esse arquivo é sempre a versão mais nova.

## Versões

Cada versão fica em `Development Notes/BETA 0.N/`, com um README do que mudou. Cada versão é desenvolvida em um branch próprio (`beta-0.N`) e depois mesclada no `main`.

| Versão | O que mudou |
|---|---|
| [BETA 0.1](Development%20Notes/BETA%200.1/) | Primeira versão jogável. |
